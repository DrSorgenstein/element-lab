Read the periodic table in 3 steps

01 • Find the number

Atomic number = number of protons. In a neutral atom, electrons equal protons.

02 • Notice the location

Rows are periods. Columns are groups. Elements in a group often share chemical properties.

03 • See the pattern

Use the colors to compare families. Noble gases are generally unreactive; alkali metals are highly reactive.
